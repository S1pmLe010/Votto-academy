# VOTTO Academy

React + Vite learning academy UI.

## Run

```bash
npm install
npm run dev
```

## Structure

- `src/api` — API layer
- `src/components` — reusable UI components
- `src/data` — modules, lessons, questions and rewards
- `src/pages` — route pages
- `src/store` — localStorage-backed app state
- `src/styles` — optional style modules
- `src/utils` — shared utilities
- `src/main.jsx` — application entry
- `src/styles.css` — global styles

Note: the uploaded source contained the complete JSX/app logic but did not contain the original CSS, so `src/styles.css` is a minimal placeholder.
